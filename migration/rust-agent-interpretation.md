# R25 Local agent interpretation validation

The native interpretation reuses the approved provider contract and the built-in diary event validator. It checks that diary mutations carry event data and that a correction identifies its target. A new batch can link one medication draft to a confirmed migraine draft within the same batch. The validator checks link indices, existing relationships and language tags.

The pinned Python agent produced 22 synthetic interpretation cases. Rust matched acceptance, intent, events, identifiers, links and language on every case. The Linux arm64 tests peaked at 9,740,288 bytes under a 32 MiB cap with zero swap.

Runtime processing still applies trusted message evidence, permissions and current target state before a diary mutation.
