# Independent Telegram controls

Authenticated intake classifies the same nine short commands as the existing Python worker. A voice caption with arguments to `/goals` stays in the ordinary work queue. Edits continue as diary revisions. The inbox and its ownership job record the lane together.

A native control worker claims from the short database pool. Each lane retains its own provider order, so a running diary job leaves a control eligible. Existing native ownership jobs without a lane default to diary processing.

The test matched 16 Python decisions on disposable TimescaleDB, including Unicode whitespace, command case and bot-name suffixes, plain text, and voice captions. It then claimed and completed the earliest control while an older diary lease remained active. The Linux ARM64 run used 8,015,872 bytes under a 32 MiB limit with no swap.
