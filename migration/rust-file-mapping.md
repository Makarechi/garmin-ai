# File mapping and confirmation

A file mapping declares the source and device, tracker, timezone, row and
time columns, units, decimal separator and null markers. Missing or invalid
fields produce a redacted error. The parsed mapping preserves the field
order used in previews and canonical defaults for optional fields.

The confirmation digest covers the exact file digest, normalized mapping,
schema digest and installed definition version. The native Linux ARM64
fixture matched pinned Python for 93 decisions, including Unicode names,
duplicates, invalid data and the 16,000-byte ceiling. The test ran at a
32 MiB limit with zero swap or OOM events.
