# Security reports

Please do not disclose a vulnerability or include credentials, health records, raw
exports, voice recordings, or private logs in a public issue or pull request.

Use GitHub's private **Report a vulnerability** flow for this repository if it is
available. If GitHub does not offer that flow, open an issue containing only a
request for a private contact channel, with no vulnerability details or attachments.
The maintainer will arrange a private exchange. Remove tokens and personal data from
reproduction steps and use synthetic data whenever possible.

Supported security work currently covers the `main` branch and its published
release tags, if any. The maintainer will acknowledge reports and coordinate a fix
and disclosure; this file does not promise a response deadline.
