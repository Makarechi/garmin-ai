# Garmin AI

Local-first personal health and activity intelligence based on Garmin data,
with Telegram as the everyday interface and MCP access for analysis.

## Status

Project setup only. Garmin synchronization, storage, Telegram, and analytics
are not implemented yet.

Development proceeds in small, verified pull requests into `main`.
Credentials, Garmin tokens, and personal health records must stay out of Git.

See the [development workflow](CONTRIBUTING.md) and [roadmap](docs/roadmap.md).
