# Running comparability (GA-20, first phase)

Whole-activity meters-per-heartbeat summaries are now chronological rather than a
global performance ranking. Observed activity types form separate descriptive
groups: treadmill, trail, indoor, track and ordinary running are never silently
ranked together. Each row explicitly says physiological comparability is not yet
established and lists missing matching inputs: route, weather, sensor provenance,
steady-state segments and subjective exertion. Missing ascent remains unknown.

An identical type is not evidence of the same route or conditions. This phase
neither infers route/weather corrections nor calls a faster run healthier. Existing
as-of sleep/HRV/readiness context and numerical summary calculations are preserved.

Segment matching, warm-up/stop exclusions, route/elevation and HR-band matching,
versioned sensors/zones, uncertainty and RPE/recovery tradeoffs remain subsequent
phases after the required canonical sources become available. Synthetic tests
cover mixed types, same-type uncertainty, ordering and empty input.
