# Public capabilities and roadmap / Публичные возможности и план

**Evidence snapshots / Срезы доказательств:** core and integration code at [`4200b84f`](https://github.com/Makarechi/garmin-ai/tree/4200b84fc603438ac54ae46c70427753e56ce3cc) (2026-10-04), browser demo at [`bd420998`](https://github.com/Makarechi/garmin-ai/tree/bd4209985a5392be55cdf9683e388377da7cc679) (2026-10-05), local web chat at [`c5238447`](https://github.com/Makarechi/garmin-ai/tree/c52384473acfc9b945c3a75ac27a2941c448a3ee) and installer smoke at [`d06e462c`](https://github.com/Makarechi/garmin-ai/tree/d06e462c288e8b521d7a692aac1af0c05bd5d47b) (2026-10-07). These are development commits, not a supported release. / Основной код и подключения сверены на первом коммите, браузерное демо — на втором; более поздние проверки веб-чата и установщика приведены отдельно. Это коммиты разработки, а не поддерживаемый выпуск.

**Status key / Обозначения:** `Code` = path exists / путь реализован; `Synthetic` = checked with synthetic data or a mocked external service / проверен на синтетике или с подменой внешнего сервиса; `Historical live` = a dated past check, not current release evidence / прежняя датированная проверка, не доказательство для текущего выпуска; `Release` = versioned distribution with current transport and operational acceptance / версионная поставка с актуальной проверкой транспорта и эксплуатации. No row below has `Release` status. / Ни одна строка ниже не имеет статуса `Release`.

Code and test evidence links point to the exact cited commits; current guides use relative links. Tests named here cover their stated path; a service test alone does not prove a browser, Telegram network, Garmin account or model provider. The [older verification record](verification.md) describes limited live checks on 2026-09-08, not this commit. / Ссылки на код и тесты ведут на точные коммиты; ссылки на действующие инструкции остаются относительными. Тест подтверждает только указанный путь: проверка сервиса не доказывает работу браузера, сети Telegram, аккаунта Garmin или провайдера модели. [Прежний отчёт](verification.md) описывает ограниченные live-проверки 2026-09-08, а не этот коммит.

## Garmin source detail / Подробности источника Garmin

The adapter inspection used `python-garminconnect` commit [`5511c729`](https://github.com/cyberjunky/python-garminconnect/tree/5511c729b4f92713c6b6bfdd5f8d1ebb4363f4cd), reported version 0.3.12, with a bounded manual probe of at most 31 dates, 100 activity summaries and five FIT/detail exports. It did **not** certify any account's available measurements. / Адаптер изучался для коммита `5511c729` (`0.3.12`); ручная проба была ограничена 31 датой, 100 тренировками и пятью выгрузками FIT/деталей. Это **не** подтверждает наличие метрик в конкретном аккаунте.

| Source group / Группа | Raw / Исходник | Canonical / Нормализация | Query / Запрос | Time and format limits / Время и формат |
|---|---|---|---|---|
| Daily: steps, sleep/stages, HRV, resting HR, stress, Body Battery, hydration, readiness, VO2max / Дневные показатели | JSON archive / JSON-архив | Selected fields in `HealthDay` / отдельные поля `HealthDay` | `health_range`, `health_snapshot` / те же запросы | Day, nullable; no completeness guarantee / сутки, возможны пропуски |
| Intraday: heart rate, stress, Body Battery, SpO2, respiration, HRV, step buckets / Внутридневные ряды | JSON archive / JSON-архив | Selected observations / отдельные наблюдения | `metric_series` for catalogued keys / для метрик каталога | Source timestamps, sparse values; hydration is daily only / отметки времени источника, редкие значения; вода только за сутки |
| Activities, details, splits, HR zones, weather, FIT samples / Тренировки, детали, части, пульсовые зоны, погода, FIT | JSON + original FIT when fetched / JSON и исходный FIT при получении | Activity and structured parts / тренировка и структурированные части | `list_activities`, `activity_details`, paginated samples / список, детали, постраничные пробы | Activity time range, paginated summaries; weather is saved context, not a live weather connector / время тренировки, постраничные сводки; погода — сохранённый контекст |

## Release blockers and next work / Блокеры выпуска и дальнейшая работа

The [UT-01–UT-53 manifest](../tests/universal_acceptance_manifest.json) and [GA-01–GA-32 operational record](operational-acceptance.md) remain the acceptance sources. Existing privacy, consent, correction, delivery and interval regression tests must pass on the candidate commit; a critical failure blocks the affected public scenario. At this baseline there is no complete live/operational release audit, so no capability is marked supported. / [Реестр UT-01–UT-53](../tests/universal_acceptance_manifest.json) и [срез GA-01–GA-32](operational-acceptance.md) остаются источниками критериев. На коммите кандидата должны пройти регрессии приватности, согласия, исправлений, доставки и интервалов; критический сбой блокирует соответствующий публичный сценарий. Полного актуального live- и эксплуатационного аудита нет, поэтому поддерживаемых возможностей пока не заявлено.

One public roadmap, in order of release value / Единый публичный план в порядке ценности для выпуска:

1. **Interactive demo (CP-04, development implementation)**: the fictional tracker, correction and analysis loop is browser-tested; a supported release remains pending. / **Интерактивное демо (CP-04, реализация для разработки)**: создание трекера, исправление записи и анализ проверены в браузере на вымышленных данных; поддерживаемый выпуск ещё предстоит.
2. **Versioned install and safe update (CP-05)**: a digest-pinned Docker candidate passed one local arm64 install and restart smoke test; native platform checks, third-party notices and independent-host restore remain. / **Версионная установка и безопасное обновление (CP-05)**: кандидат с образом по digest прошёл одну локальную проверку установки и перезапуска arm64; нужны проверки на нативных платформах, уведомления о сторонних лицензиях и восстановление на другом хосте.
3. **Second model and channel (CP-07–09)**: authenticated local web chat and the experimental v1 extension kit passed synthetic checks; a specific local model and generic inbound extension route remain pending. / **Вторая модель и канал (CP-07–09)**: авторизованный локальный веб-чат и экспериментальный набор расширений v1 прошли синтетические проверки; конкретная локальная модель и общий входящий маршрут расширений остаются впереди.
4. **Independent source and scenario packs (CP-06, CP-10)**: declarative scenario packs and strict local CSV/JSON import are synthetic-tested; device-specific formats and broader source normalization remain pending. / **Независимый источник и сценарные пакеты (CP-06, CP-10)**: декларативные сценарные пакеты и строгий локальный импорт CSV/JSON проверены на синтетике; форматы конкретных устройств и более широкая нормализация источников остаются впереди.
5. **Release evidence and small opt-in pilot (CP-11–12)**: current regression review, provider/device checks, seven-day run, independent-host restore and measured onboarding. / **Доказательства готовности и небольшой добровольный пилот (CP-11–12)**: актуальные регрессии, проверки провайдеров и устройств, семь суток работы, восстановление на другом хосте и измерение удобства настройки.

synthetic task flow, so no local model backend is supported. / [Проверка
