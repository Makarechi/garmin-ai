# GA-31: подготовка проверки Connect IQ

Это проверка документации от 2026-09-10, а не завершённый spike на конкретных часах. Модель Garmin и ОС телефона ещё не указаны. Сборка SDK, симулятор, доставка без телефона и хранение на устройстве не проверены; поддержку устройства не обещаем.

| Возможность | Подтверждено документацией | Что проверить на выбранном устройстве |
|---|---|---|
| Локальная очередь | Application.Storage доступен с API 2.4.0; одно значение ограничено 32 KB, общий объём зависит от устройства | Вместимость, переполнение, перезапуск, сохранность до ACK |
| Запись в фоне | Запись/удаление Storage из background требует поддержки Connect IQ 3.2.0 | API level и исключения на реальной модели |
| Периодический фон | Temporal events имеют минимальный интервал 5 минут; регистрируется одно событие | Пробуждение и ограничения батареи; это не гарантия доставки в реальном времени |
| Передача | Communications описывает запросы и ошибки связи/Wi-Fi | Транспорт Garmin Connect на выбранной ОС, потеря связи и повторная доставка |

Источники: [Storage](https://developer.garmin.com/connect-iq/api-docs/Toybox/Application/Storage.html), [Background.registerForTemporalEvent](https://developer.garmin.com/connect-iq/api-docs/Toybox/Background.html#registerForTemporalEvent-instance_function), [Communications](https://developer.garmin.com/connect-iq/api-docs/Toybox/Communications.html).

После выбора устройства: зафиксировать API level и тип приложения, собрать минимальный клиент, проверить запись события с UUID и временем устройства, отсутствие телефона, повтор upload/ACK, переполнение очереди, drift часов и отзыв ограниченного credential. На часы не передавать Garmin password, LLM key или право полного экспорта. Эти пункты — критерии будущей реализации, не отчёт о выполненных проверках.
